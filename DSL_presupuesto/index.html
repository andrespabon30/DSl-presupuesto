Sintaxis soportada

INGRESO FIJO NOMINA = 2500000; GASTO FIJO LUZ = 2500; GASTO HORMIGA CAFE = 3000; GASTO VARIABLE MERCADO = 250000; CALCULAR PRESUPUESTO;

La estructura obligatoria es TIPO CLASIFICACION IDENTIFICADOR = VALOR;. Las clasificaciones validas son FIJO, HORMIGA y VARIABLE.

El sintactico acepta numeros negativos, pero el semantico los rechaza porque el presupuesto no permite valores menores o iguales a cero.
